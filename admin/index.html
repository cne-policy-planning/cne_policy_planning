파일·폴더 넣기

📂
파일이나 폴더를 통째로 끌어다 놓으세요 하위 폴더까지 모두 읽습니다. PDF는 번호 목차·서식 링크를 자동으로 뽑고 원본 PDF도 사이트에 함께 올립니다(15MB 이하 권장). HWPX는 본문만, HWP·엑셀 등은 자료명·검색어로만 검색됩니다.
폴더 이름 규칙 — 이렇게 나눠 두면 자동으로 채워집니다
  • 학교급: 폴더나 파일 이름에 유치원·유아, 초등, 중등·중학, 특수가 들어 있으면 그 학교급으로 정합니다. 안쪽 폴더가 우선입니다. 폴더 이름이 공통(또는 공통자료)이면 공통입니다.
  • 부서: 폴더 이름이 부서 이름(예: 민주시민교육과)과 같으면 그 부서. 원 출처가 학교업무자료실이면 「교무학사 공통자료」.
  • 연도: 파일 이름(없으면 폴더 이름)의 2027 같은 네 자리 연도.
  • 업무 분류·원 출처: 폴더 이름이 분류 목록(예: 교무학사실무)이나 자료실 이름(예: 학교업무자료실)과 같으면 그 값.
  • 덮어쓰기: 연도·띄어쓰기·(최종) 같은 표시를 뺀 이름이 기존 자료와 같으면 그 자료를 덮어씁니다(비슷하면 확인 표시). 자료 ID와 사이트 주소는 그대로이고, 고쳐 둔 링크·검색어는 이어받습니다. 덮어쓰기 전에 확인 팝업이 한 번 뜹니다.

점검

저장 전에 자료 목록·학교급별 색인·자료별 파일이 서로 맞는지 검사합니다.

원본 파일 창고

원본 파일(PDF·HWP·엑셀…)은 사이트 용량 한도(1GB) 때문에 연도별 창고 저장소(cne_files_연도_번호)에 나눠 담습니다. 사용자 화면에서는 링크 없이 바로 내려받을 수 있습니다. 새 연도 자료로 다 바꾼 뒤에는 지난 연도 창고를 통째로 지워도 됩니다.

사이트에 반영

점검을 통과하면 바뀐 파일만 GitHub에 올립니다. 1~2분 뒤 공개 사이트에서 검색됩니다.

변경 기록

관리자 도구를 열 때마다 GitHub의 변경 기록을 확인해, 이 PC의 관리자 도구가 하지 않은 변경이 있으면 알려 드립니다. 여기서 최근 기록을 직접 볼 수도 있습니다.

예비 방법: 저장소 폴더 저장 · ZIP 내보내기

GitHub 연결이 안 될 때 씁니다. 폴더에 저장하거나 ZIP으로 받은 뒤, GitHub Desktop 또는 GitHub 웹 화면으로 직접 올려야 합니다.

※ 공개 사이트의 데이터 파일은 누구나 내려받을 수 있습니다. 보호가 필요한 자료는 올리지 마세요. 출입증은 이 PC의 브라우저에만 보관되며 사이트 파일에는 들어가지 않습니다.
